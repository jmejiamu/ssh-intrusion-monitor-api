# SSH Intrusion Monitor API

Backend API for the SSH Intrusion Detection & Monitoring System. It receives security events from the Raspberry Pi monitoring agent, validates and stores them in MongoDB, and streams new events to the React Native dashboard in real time.

## Features

- REST API for security event ingestion
- Event validation with Zod
- MongoDB event storage
- Severity and event-type filtering
- Pagination for historical events
- Real-time event streaming with Socket.io
- TypeScript-based API

## Architecture

```text
Python Monitor
      ↓
  REST API
      ↓
Validation (Zod)
      ↓
   MongoDB
      ↓
  Socket.io
      ↓
Mobile Dashboard
```

## API Endpoints

### Create Security Event

```http
POST /api/events
```

Receives security events generated by the Raspberry Pi monitoring agent.

Example:

```json
{
  "type": "possible_brute_force",
  "severity": "high",
  "username": "admin",
  "ip_address": "192.168.1.50",
  "attempt_count": 5,
  "timestamp": "2026-09-07T20:30:00Z",
  "should_alert": true
}
```

### Get Security Events

```http
GET /api/events
```

Supports pagination and filtering.

Examples:

```text
/api/events?page=1&limit=5
/api/events?severity=high
/api/events?severity=medium
/api/events?type=possible_brute_force
```

## Real-Time Events

When a new security event is received and stored, the API emits a Socket.io event:

```text
security_event
```

The React Native dashboard listens for this event to display new activity in real time.

## Setup

Create a `.env` file:

```env
PORT=3001
MONGODB_URI=YOUR_MONGODB_CONNECTION_STRING
```

Install dependencies:

```bash
pnpm install
```

Start the development server:

```bash
pnpm dev
```
